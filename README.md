# STRIKERS 1945 — C / raylib

고전 아케이드 슈팅게임 **스트라이커즈 1945**를 C언어와 raylib으로 구현한
종스크롤 슈팅게임입니다. 이미지·사운드 등 외부 에셋 파일 없이
`main.c` 단 하나의 소스 파일로 빌드·실행됩니다.

## 게임 소개

- 하늘(바다) 위를 스크롤하며 몰려오는 적기 편대를 격추하는 세로형 슈팅게임
- 일정 웨이브를 버티면 **WARNING** 연출과 함께 대형 폭격기 보스 등장
- 보스 격추 → 스테이지 클리어 → 스테이지가 올라갈수록 적 속도·탄속·체력 증가
- 목숨 3개(잔기 2) + 폭탄 2개로 시작, 피격 시 무기 1단계 강등

## 조작 방법

| 키 | 동작 |
|---|---|
| 방향키 / WASD | 기체 이동 |
| Z / Space | 발사 (누르고 있으면 자동 연사) |
| X | 폭탄 (화면의 적 탄환 전부 소멸 + 광역 피해) |
| P | 일시정지 |
| Enter | 게임 시작 / 다음 스테이지 / 타이틀로 |

## 게임 시스템

- **무기 파워업 4단계** : P 아이템 획득 시 단발 → 2연장 → 3way → 5way
- **아이템 3종** : `P`(무기 강화), `B`(폭탄 +1), `$`(점수 +1000)
- **적 3종** : 소형 전투기(직진 편대), 중형 전투기(좌우 왕복 사수), 중폭격기(호버링 + 부채탄)
- **보스 패턴 3종** : 조준탄 연사 → 원형 탄막 → 부채꼴 5연발을 3.5초마다 교대
- 피격 후 2.5초 무적(깜빡임), 실제 오락실 게임처럼 작은 피격 판정

## 개발 환경 및 빌드 방법

- **OS** : Windows 10/11
- **IDE** : Visual Studio 2022 (C++를 사용한 데스크톱 개발 워크로드)
- **언어** : C (ISO C17)
- **라이브러리** : raylib 6.2 (https://github.com/raysan5/raylib/releases)

### 1) raylib 설치
1.  Visual Studio 프로젝트 설정 NuGet패키지관리클릭
2. 찾아보기에서 raylib 설치
또는 
1. GitHub Releases에서 `raylib-6.2_win64_msvc16.zip` 다운로드
2. `C:\raylib` 에 압축 해제 → `C:\raylib\include`, `C:\raylib\lib` 구조가 되도록 배치
### 2) Visual Studio 프로젝트 설정
1. **빈 프로젝트** 생성 → 소스 파일에 `main.c` 추가
2. 솔루션 구성을 **x64** 로 변경
3. 프로젝트 속성(모든 구성)에서:
   - `C/C++ → 일반 → 추가 포함 디렉터리` : `C:\raylib\include`
   - `C/C++ → 언어 → C 언어 표준` : **ISO C17 (/std:c17)**
   - `링커 → 일반 → 추가 라이브러리 디렉터리` : `C:\raylib\lib`
   - `링커 → 입력 → 추가 종속성` :
     `raylib.lib;winmm.lib;gdi32.lib;opengl32.lib;kernel32.lib;user32.lib;shell32.lib`
4. `Ctrl + F5` 로 빌드/실행

## 구현 포인트 (기술 설명)

- **객체 풀(Object Pool)** : 탄환·적·아이템·파티클을 고정 크기 구조체 배열로 관리,
  `active` 플래그로 재활용해 실행 중 동적 할당 없음
- **상태 머신** : TITLE → PLAY → CLEAR/OVER 흐름을 `enum GameState`로 관리
- **프레임 독립 이동** : 모든 이동에 `GetFrameTime()`(dt)을 곱해 FPS와 무관하게 동일한 속도 유지
- **충돌 판정** : 원-원 거리 제곱 비교(`dx*dx + dy*dy < r*r`)로 sqrt 연산 제거
- **조준탄** : `atan2f(py - y, px - x)`로 플레이어 방향 각도 계산 후 탄환 발사
- **도형 기반 그래픽** : 이미지 파일 대신 `DrawTriangle/DrawCircle/DrawRectangle` 조합으로 기체를 렌더링
- **사운드 합성** : 사운드 파일 대신 사각파·화이트 노이즈 PCM을 직접 생성해
  `LoadSoundFromWave()`로 효과음 4종(발사/폭발/파워업/폭탄) 구현

## 코드 설명 (간단 정리)

`main.c` 하나에 아래와 같은 구조로 구성되어 있습니다.

| 부분 | 역할 |
|---|---|
| 상수 (`#define`) | 화면 크기, 최대 탄환·적 수, 속도 등 게임 밸런스 수치 모음 |
| 구조체 (`Player`, `Bullet`, `Enemy`, `Item`, `Particle`, `Boss`) | 위치·속도·체력·`active` 플래그를 가진 게임 오브젝트 단위 |
| `InitGame()` | 플레이어·보스·객체 풀 초기화, 스테이지 시작 세팅 |
| `SpawnEnemy()` / `FireBullet()` | 풀에서 꺼져 있는 슬롯을 찾아 적·탄환 생성 |
| `UpdateGame()` | 키 입력, 이동, 스폰 타이머, 충돌, 아이템, 보스 패턴 갱신 |
| `DrawGame()` | 배경 스크롤, 기체·탄환·아이템·HUD(점수·목숨·폭탄) 그리기 |
| 충돌 판정 부분 | 원-원 거리 비교로 플레이어↔적탄, 탄환↔적 충돌 처리 |
| 사운드 생성 부분 | 사각파·화이트 노이즈 PCM 데이터를 직접 만들어 효과음으로 로드 |
| `main()` | 창 생성 → 상태 머신 기반 `Update → Draw` 게임 루프 → 종료 |

실행 흐름: `main()`에서 창과 사운드를 초기화한 뒤, 현재 `GameState`에 따라
타이틀/플레이/클리어/게임오버 화면의 Update·Draw 함수를 매 프레임 호출하는 구조입니다.
